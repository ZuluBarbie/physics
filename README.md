# Physics

A beginner-friendly Python project for practising basic mechanics.

## Run

Install Python 3, then run:

```sh
python physics.py
```

No extra packages are required. The example calculates force, kinetic energy,
and weight using SI units: kilograms, metres, and seconds.

## Formulas

- Force: F = ma (newtons)
- Kinetic energy: E = 0.5mv² (joules)
- Weight: W = mg (newtons), using g = 9.81 m/s²

Edit the example values in `physics.py` to explore different results.
